# AI 表格 Web 应用产品方案

更新时间：2026-09-14

具体开发拆分、接口与验收标准参见 [AI 表格 Web 应用具体实施方案](./AI_TABLE_IMPLEMENTATION_PLAN.md)。

建议采用「保留表格组件 + 独立 AI Web 应用」的路线，第一阶段定位为：

> 面向运营人员的 AI 表格工作台：导入 Excel，用一句话完成清洗、公式生成和数据分析，结果可核对、可撤销。

## 1. 现有基础

当前项目已经有可复用的底座：

- [Workbook 引擎](../src/core/Workbook.js)。
- Vue 表格编辑器。
- 导入导出、基础公式、撤销重做。
- [插件体系](./PLUGIN_DEVELOPMENT.md)。

产品化还需要补上文档管理、AI 执行流程、账号权限和云端保存。

当前跨表公式尚不支持，协同服务器也是参考实现，首版不依赖这两项。具体边界参见 [项目说明](../README_zh.md)、[公式手册](./FORMULAS.md)和[协同接入指南](./REALTIME_COLLABORATION_INTEGRATION.md)。

## 2. 首版功能

先聚焦经常处理订单表、销售表的运营人员。

| 优先级 | 功能 | 用户怎么说 | 产品交付什么 |
| --- | --- | --- | --- |
| P0 | AI 生成公式 | “根据单价和数量生成销售额列” | 公式、结果预览、确认写入 |
| P0 | AI 清洗 | “统一日期格式，标出重复手机号” | 处理规则、修改前后对比 |
| P0 | AI 问数据 | “各地区销售额分别是多少？” | 确定性计算结果、来源范围和统计口径 |
| P1 | AI 批量填充 | “根据客户备注添加意向标签” | 新增结果列、进度、失败重试 |

基础功能保留新建、导入、编辑、保存和导出。

图表、数据库连接、实时多人协作、自动化工作流放到后续。

## 3. 使用体验

主界面直接进入工作台：

- 顶部：文件操作与保存状态。
- 左侧：可收起的文档列表。
- 中间：表格编辑器。
- 右侧：AI 面板。

核心交互流程：

**导入文件 → 选择范围 → 输入要求 → 查看处理计划和差异 → 确认应用 → 撤销或导出**

例如输入“统一订单日期格式”后，应展示处理范围、目标格式、影响数量和异常值，而不是只回复“已完成”。遇到日期歧义或缺失业务口径，先让用户确认。

## 4. 技术方案

沿用 Vue 3 和现有组件，新建独立 Web 应用，先不调整组件库的发布结构。

```text
Web 应用：文档管理、表格编辑器、AI 面板
    ↓ 授权范围、表结构、必要样本
AI 服务：鉴权、模型调用、结构化计划、额度
    ↓ 白名单操作计划
应用侧执行器：校验、预演、差异、确认、撤销
    ↓
现有 Workbook：读写、公式计算、渲染、导入导出
```

### 4.1 模块职责

- **AI 适配层**：先放在应用侧，通过公开 API 和插件接口连接 Workbook，稳定后再考虑独立插件包。
- **后端**：建议 Node.js + Fastify；正式上线用 PostgreSQL 保存用户、文档版本和任务记录，对象存储保存原始文件。
- **模型接入**：首版接一家支持工具调用和结构化输出的模型，密钥只放服务端。
- **数据处理**：模型负责理解需求、选择操作；求和、分组、去重由确定性代码执行，不能让模型根据几行样本猜全表结果。

### 4.2 安全与一致性边界

1. 所有写操作先校验、预览、确认；只允许白名单操作，不执行模型生成的任意 JavaScript。
2. 新增任务版本校验和失败回滚。现有批量更新、批量历史可以复用，但不等于完整事务；预览期间数据变化后必须重新校验。
3. 默认只提交必要字段和授权数据，提供敏感列排除；单元格里的文字始终当数据，不当执行指令。
4. AI 填充采用异步任务、缓存和结果回写。现有自定义公式是同步接口，首版不直接做联网的 `=AI()`。

## 5. 实施节奏

按 **2 名熟悉项目的工程师、现有组件稳定** 粗估：

| 阶段 | 时间 | 验收目标 |
| --- | --- | --- |
| 验证版 | 第 1 周 | 导入 → AI 公式 → 预览 → 应用 → 一次撤销 → 导出 |
| MVP | 第 2–3 周 | 清洗、分析问答、来源定位、版本冲突处理、回归测试 |
| 内测版 | 第 4–6 周 | 登录、云端保存、额度、任务重试、成本统计 |

关键验收标准：

- 统计与基准数据一致。
- 取消不改表。
- 失败不留下部分修改。
- 撤销能完整恢复。

IndexedDB 保留为本地缓存，不代替云端保存。

## 6. 商业路径

组件库继续服务开发者，Web 应用面向最终用户收费：

- 免费：基础编辑和少量 AI 额度。
- 付费：增加任务额度、批量处理及云端历史。
- 后续：团队权限和私有部署。

先找 5–10 位运营人员，用真实 Excel 验证以下指标，再确定价格：

- 任务成功率。
- 结果应用率。
- 每周复用次数。
- 单个成功任务成本。

## 7. 推荐起点

第一步只打通：

**导入订单表，用一句话生成销售额列，预览后写入并可撤销。**

这条链路能同时验证 AI 理解、表格执行和用户信任，也是后续功能最值得复用的基础。
