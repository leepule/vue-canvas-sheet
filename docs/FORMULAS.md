# 公式使用手册

本文档列出 `vue-canvas-sheet` 公式计算引擎当前支持的运算符、函数、单元格引用语法及其用法示例。

> 引擎说明：公式由预构建的 **WASM 引擎**（Rust）执行；当运行环境不支持 `SharedArrayBuffer` / WASM 时，自动降级到 **JS 引擎**。两套引擎支持的函数与运算符优先级一致，结果相同。
>
> 所有公式以 `=` 开头，如 `=SUM(A1:A10)`。

---

## 1. 运算符

| 运算符 | 说明 | 示例 | 结果 |
| :--- | :--- | :--- | :--- |
| `+` | 加法 | `=1 + 2` | `3` |
| `-` | 减法 / 负号 | `=10 - 5`<br>`=-10` | `5`<br>`-10` |
| `*` | 乘法 | `=3 * 4` | `12` |
| `/` | 除法（除零返回 `#DIV/0!`） | `=12 / 4` | `3` |
| `&` | 字符串拼接 | `="A" & "B"` | `"AB"` |
| `=` | 等于（返回布尔） | `=A1 = 10` | `TRUE` / `FALSE` |
| `<>` | 不等于 | `=A1 <> 0` | `TRUE` / `FALSE` |
| `<` `>` `<=` `>=` | 大小比较 | `=A1 >= 60` | `TRUE` / `FALSE` |

> 比较运算返回布尔值（`TRUE` / `FALSE`），可作为 `IF` 的条件。

### 1.1 运算符优先级

运算符遵循标准优先级（与 Excel / 数学一致），从高到低：

| 优先级 | 运算符 |
| :--- | :--- |
| 高 | `*` `/` |
| ↓ | `+` `-` |
| ↓ | `&`（拼接） |
| 低 | `=` `<>` `<` `>` `<=` `>=`（比较） |

同级运算符左结合。例如：

| 公式 | 结果 | 说明 |
| :--- | :--- | :--- |
| `=1 + 2 * 3` | `7` | 先乘后加 |
| `=10 - 2 - 3` | `5` | 左结合 |
| `=2 + 3 > 4` | `TRUE` | 先算 `2+3`，再比较 |

用括号 `()` 可改变求值顺序：`=(1 + 2) * 3` → `9`。

> WASM 引擎与 JS 降级引擎采用一致的优先级，结果相同。

## 2. 单元格引用

| 形式 | 示例 | 说明 |
| :--- | :--- | :--- |
| A1 引用 | `=A1`、`=B10` | 列字母 + 行号 |
| 绝对引用 | `=$A$1`、`=$A1`、`=A$1` | `$` 锁定列/行 |
| 范围 | `=SUM(A1:B10)` | 用 `:` 表示矩形区域 |
| R1C1 引用 | `=R1C1`、`=R[-1]C[0]` | 行列号 / 相对偏移 |

字面量：

- **数字**：`=3.14`、`=-10`
- **字符串**：用双引号包裹，`="Hello"`
- **布尔**：`=TRUE`、`=FALSE`（大小写不敏感）

---

## 3. 聚合函数（Aggregate）

接受单元格范围（如 `A1:B10`）或多个独立参数。

| 函数 | 说明 | 示例 |
| :--- | :--- | :--- |
| **SUM** | 求和 | `=SUM(A1:A10, 5)` |
| **AVERAGE** | 平均值（无参数时返回 `#DIV/0!`） | `=AVERAGE(B1:B20)` |
| **MAX** | 最大值 | `=MAX(A1, B1, C1)` |
| **MIN** | 最小值 | `=MIN(A1:C10)` |
| **COUNT** | 计数（仅统计数字） | `=COUNT(A1:A10)` |
| **COUNTA** | 计数（统计所有传入参数 / 非空单元格） | `=COUNTA(A1:A10)` |

---

## 4. 数学函数（Math）

| 函数 | 说明 | 示例 | 结果 |
| :--- | :--- | :--- | :--- |
| **ROUND** | 四舍五入到指定小数位 | `=ROUND(3.14159, 2)` | `3.14` |
| **ABS** | 绝对值 | `=ABS(-5)` | `5` |
| **INT** | 向下取整 | `=INT(3.9)` | `3` |
| **SQRT** | 平方根（负数返回 `#NUM!`） | `=SQRT(16)` | `4` |

---

## 5. 文本函数（Text）

| 函数 | 说明 | 示例 | 结果 |
| :--- | :--- | :--- | :--- |
| **CONCAT** | 拼接字符串 | `=CONCAT("A", "B", "C")` | `"ABC"` |
| **LEFT** | 从左侧提取 n 个字符 | `=LEFT("Hello", 2)` | `"He"` |
| **RIGHT** | 从右侧提取 n 个字符 | `=RIGHT("Hello", 2)` | `"lo"` |
| **LEN** | 字符串长度 | `=LEN("Hello")` | `5` |
| **UPPER** | 转大写 | `=UPPER("hello")` | `"HELLO"` |
| **LOWER** | 转小写 | `=LOWER("HELLO")` | `"hello"` |

> 提示：拼接也可用 `&` 运算符，`="姓名：" & A1` 等价于 `=CONCAT("姓名：", A1)`。

---

## 6. 逻辑函数（Logic）

| 函数 | 说明 | 示例 |
| :--- | :--- | :--- |
| **IF** | 条件判断 `IF(条件, 真值, 假值)` | `=IF(A1 >= 60, "及格", "不及格")` |
| **AND** | 逻辑与（全部为真） | `=AND(A1 > 0, B1 > 0)` |
| **OR** | 逻辑或（任一为真） | `=OR(A1 = 1, B1 = 1)` |
| **NOT** | 逻辑非 | `=NOT(A1 = 0)` |

> 真假规则：数字 `0` 为假、非 `0` 为真；空字符串为假、非空为真；`TRUE`/`FALSE` 即布尔本身。

---

## 7. 日期与时间函数（Date）

日期在底层表示为自 `1899-12-30` 起的 Excel 序列号（天数）。

| 函数 | 说明 | 示例 |
| :--- | :--- | :--- |
| **TODAY** | 当前日期（去除时间的序列号） | `=TODAY()` |
| **NOW** | 当前时间（含时间的序列号） | `=NOW()` |
| **YEAR** | 提取年份 | `=YEAR(TODAY())` |
| **MONTH** | 提取月份（1–12） | `=MONTH(TODAY())` |
| **DAY** | 提取日 | `=DAY(TODAY())` |

---

## 8. 错误代码

公式计算出错时返回以下代码：

| 代码 | 含义 |
| :--- | :--- |
| `#DIV/0!` | 除以零 / `AVERAGE` 无参数 |
| `#VALUE!` | 缺少必需参数或数据类型错误（含计算结果为 `NaN`） |
| `#NAME?` | 未知的函数名 |
| `#NUM!` | 无效数字值（如对负数开平方） |
| `#OP!` | 不支持的运算符 |
| `#ERR: <详情>` | 其他内部错误 |

---

## 9. 综合示例

```js
// 在 TableDesigner / Workbook 中写入公式单元格
wb.setCell(0, 0, { v: 90 });                       // A1 = 90
wb.setCell(1, 0, { v: 85 });                       // A2 = 85
wb.setCell(2, 0, { v: '=SUM(A1:A2)' });            // A3 = 175
wb.setCell(3, 0, { v: '=ROUND(AVERAGE(A1:A2), 1)' }); // A4 = 87.5
wb.setCell(4, 0, { v: '=IF(A3 >= 150, "达标", "未达标")' }); // A5 = "达标"
wb.setCell(5, 0, { v: '="总分：" & A3' });          // A6 = "总分：175"
```

> 完整的写入 / 读取 API 见 [Workbook API §9 公式与计算](./WORKBOOK_API.md#9-公式与计算)。
